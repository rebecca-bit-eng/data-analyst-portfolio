# Rebecca's Data Analyst Portfolio

Data analytics portfolio focused on business reporting, data quality, and Kenyan socioeconomic research. I am also a co-founder of [Black Rock Data](https://github.com/rebecca-bit-eng/BlackRockData), a Kenyan data analytics and research services company.

## Start here

The two projects below contain code for review. Both are in progress; completed findings and deployed dashboards are not yet published.

| Order | Project | What to review | Current status |
|---|---|---|---|
| 1 | [Sales Performance Dashboard](projects/01-sales-dashboard/README.md) | Python, Pandas, Plotly and Streamlit code for regional filters, sales trends and category profit reporting. | Dashboard prototype; data setup needs resolving. Forecast is a placeholder. |
| 2 | [Kenya Household Welfare & Labour Intelligence](https://github.com/rebecca-bit-eng/BlackRockData/tree/main/projects/kchs-2022) · Black Rock Data | Python ingestion and data-audit code, survey analysis plan, and documented data-access workflow. | Audit script and methodology available; survey findings and final outputs pending. |

**For business intelligence roles:** start with the [sales dashboard source](projects/01-sales-dashboard/dashboard/app.py).  
**For research and data quality roles:** start with the [KCHS audit script](https://github.com/rebecca-bit-eng/BlackRockData/blob/main/projects/kchs-2022/analysis/01_data_audit.py) and [analysis workflow](https://github.com/rebecca-bit-eng/BlackRockData/blob/main/projects/kchs-2022/analysis/README.md).

## Skills demonstrated in the available code

- **Python and Pandas:** loading data, filtering, aggregation, missingness checks, duplicate-row checks and numeric summaries.
- **Plotly and Streamlit:** interactive sales charts and regional filters.
- **Research workflow:** documenting survey design considerations, data access, planned validation and interpretation limits.
